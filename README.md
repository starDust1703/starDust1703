## 🚀 Featured Projects

### 01. LineLess — Real-Time Queue Management

A full-stack queue management application designed to keep users and administrators synchronized in real time.

**Highlights**
- ⚡ Real-time queue position and population synchronization.
- 🔐 Role-aware database access using PostgreSQL RPCs and Row-Level Security (RLS).
- 🎟️ QR-based joining, unique queue keys, and join/leave synchronization.
- 🛠️ Admin controls, including pause and resume.
- 🚀 Indexed lookups and optimized client-side state management.

**Tech Stack**

`Next.js` `React` `TypeScript` `Supabase` `PostgreSQL` `Tailwind CSS`

[**Live Demo →**](https://lineless17.vercel.app) · [**View Repository →**](https://github.com/starDust1703/lineless)

### 02. Orglytics — GSoC Organization Analytics

An analytics tool that collects historical Google Summer of Code (GSoC) organization data and predicts whether organizations are likely to participate in the following year.

**Highlights**
- 🔎 Scrapes official GSoC organization pages and historical archives.
- 📊 Tracks organization participation across five previous years.
- 📁 Exports structured organization datasets to Excel.
- 🤖 Trains and evaluates machine learning models for next-year participation prediction.
- 🌐 Provides a Next.js frontend with an API backed by Neon PostgreSQL.

**Tech Stack**

`Python` `Pandas` `Scikit-learn` `Playwright` `OpenPyXL` `Next.js` `TypeScript` `PostgreSQL`

[**Live Demo →**](https://orglytics.onrender.com) · [**View Repository →**](https://github.com/starDust1703/Orglytics)

### 03. Crack — Multiplayer Strategy Game
